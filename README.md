# RaceGame
мини игра для двоих
### В проекте реализованы:
* основное меню игры с кнопками перехода в настройки и саму игру
* панель настроек с возможностью менять игровые клавиши
* окно игры-кликера на двоих визуализированной в виде гонки. Реализовано ускорение машин при быстрых нажатиях на клавишу и замедление при бездействии
